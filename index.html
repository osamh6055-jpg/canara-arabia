إعدادات الربط مع التخزين السحابي (Supabase)

قم بإدخال بيانات مشروعك على Supabase لحفظ قطع الغيار سحابياً ومشاركتها مع جميع المستخدمين والأجهزة في الوقت الفعلي:

ملاحظة هامة للعمل على رابط GitHub Pages للجميع:
لتظهر المنتجات لجميع الزوار على الرابط العام تلقائياً، قم بفتح ملف index.html في كود الموقع وضعي رابط ومفتاح Supabase في المتغيرات: PUBLIC_SUPABASE_URL و PUBLIC_SUPABASE_KEY ثم قم برفع التعديل إلى GitHub.

كيفية إنشاء ربط سحابي مجاني في 3 دقائق:

  1. إنشاء حساب مجاني: افتح موقع supabase.com وسجل الدخول مجاناً.
  2. إنشاء مشروع جديد: اضغط New Project واكتب اسم المشروع واكتفي بالخيار المجاني (Free Tier).
  3. جلب بيانات الربط: من القائمة الجانبية في Supabase اذهب إلى Project Settings ← API وانسخ:
    • Project URL (ألصقه بالخانة الأولى أدناه)
    • Project API keys (anon / public) (ألصقه بالخانة الثانية أدناه)
  4. تجهيز الجدول بضغطة زر: اضغط على زر نسخ أوامر إنشاء الجدول SQL أدناه، ثم اذهب في Supabase إلى SQL Editor ← ألصق الأمر واضغط Run.
